# 多级标签使用指引

[简体中文](hierarchical-tags.md) | [English](hierarchical-tags.en-US.md)

标签用 `/` 分隔层级。写下 `#读书/小说/科幻` 这样的标签，就等于建出了「读书 → 小说 → 科幻」三层结构，既保留标签的灵活，又有了目录的层次。

### 在哪里浏览

第一栏「Agent 制品」下方是「标签」分区，工作区里的全部标签在这里组成一棵可折叠的树。

- 分区标题和每个有下级的标签都能折叠，展开状态会记住。
- 节点右侧的数字是这个标签及其所有下级标签下的笔记数，同一篇笔记只算一次。
- 只有大小写或空白不同的写法会合成一个节点，例如 `Topic/Kernel` 和 `topic/kernel`。
- 同级按名称排序，数字按自然顺序，开头的 Emoji 不参与排序。
- 标签某一级以 Emoji 开头时，这个 Emoji 就是节点图标。

### 在编辑器里选择标签

点击笔记顶部的标签区域打开「选择标签」，列表也是同一棵标签树：勾选任意一级都会按完整路径写入标签，搜索时会保留通往命中项的层级。

### 按标签筛选

点击任意节点，第二栏会列出带有这个标签或任一下级标签的笔记和 Agent 制品，范围是整个工作区。点击笔记卡片上的标签也会切换筛选，并在树里展开、定位到对应节点。

### 重命名与移动

在节点上点「···」或右键，选择「重命名」，对话框里显示完整路径：

- 改名字就是重命名，例如把 `读书` 改成 `阅读`。
- 改路径就是移动层级，例如把 `读书/小说` 改成 `阅读/小说`，它的下级标签一起跟着走。
- 目标路径已经存在时会先确认，再合并。
- Emoji 直接在输入框里输入即可，例如 `📚读书`。

### 移除标签

选择「移除标签」会把该节点及其所有下级标签从笔记上去掉，笔记本身保留。执行前会显示受影响的笔记数量。

### 书写约定

- 标签保存在笔记上，没有脱离笔记的空标签。
- 保存时会自动整理路径：`a / b`、`a//b`、`/a/` 都会存成 `a/b`、`a/b`、`a`。
- 层级只是展示和筛选方式，Android 和 iOS 客户端仍然按完整标签名显示和筛选。
