# HTML 制品

[English](html-artifacts.md)

**HTML 制品**是 AI Agent 生成的单个可交互网页，比如报告、看板、幻灯片或小工具，你可以把它保存在 EdgeEver 里阅读。制品是笔记的一种：它有标题、标签和所在位置，和普通笔记一样同步、进回收站，也能被搜索到。制品的网页不能在 EdgeEver 里逐字编辑，只能用新的 HTML 文件整体替换，之前的版本会留在版本历史里。

## Agent 制品（制品库）

制品放在侧边栏笔记本下方单独的一棵树里，名为 **Agent 制品**。每个工作区只有一个制品库。第一次打开它或第一次导入制品时，EdgeEver 才会创建它，所以第一次打开需要联网。

- 用**制品文件夹**归类制品，文件夹可以嵌套。在制品库上用「新建制品文件夹」，在文件夹上用「新建子文件夹」。
- 制品库可以改名，但不能删除或移动。
- 制品库和笔记本互相隔离：制品只能留在制品库里，普通笔记不能移进制品库，笔记本和制品文件夹也不能跨过这条边界移动。跨边界的移动会被拒绝，并提示「不能移到这里」。
- 只有不含制品的文件夹才能删除，其中的空子文件夹会一起删除。
- 「全部笔记」里不显示制品。搜索、按标签筛选或打开制品所在文件夹时仍能看到它们，快速切换里会用网页图标标出制品。

## 导入

Web 端和桌面端都能导入制品，导入需要联网。

- 打开「Agent 制品」或其中某个文件夹，主按钮会变成「导入 HTML」，选择一个或多个 `.html`、`.htm` 文件即可。在制品库以外，「新建笔记」旁边的「更多类型」菜单里有「导入 HTML 制品」。
- 也可以把文件拖到笔记列表上。在制品库里，拖入的文件全部作为制品导入；在其他位置，`.html`/`.htm` 文件导入到制品库根目录，其他文件仍按普通 Markdown 导入处理。
- 制品会放进当前选中的文件夹，没有选中文件夹时放进制品库根目录。
- 标题取自网页的 `<title>`，没有时用文件名，之后可以修改。
- 多个文件会逐个导入。某个文件失败不影响其他文件，导入结束后会逐条列出失败原因。

网页按**单个文件**保存。网页引用的本地相对路径资源（如 `./style.css`、`images/a.png`、`/app.js`）不会一起导入。导入后 EdgeEver 会列出这些「缺少的本地资源」，提醒你相应部分可能显示不全。通过 `https://…` 地址加载的资源和内联的 `data:` 资源不受影响，因为网页可以访问外网。

## 阅读

选中制品后，第三栏会打开制品阅读器。工具栏包括：

- 标题（可直接修改）和标签；
- 「刷新」「全屏沉浸」（按 Esc 退出）「导出图片」「下载 HTML」（下载原始文件）；
- 「替换内容…」和「版本历史」；
- 「移入回收站」。

网页中会打开新窗口的链接（`target="_blank"`、`window.open`）会在浏览器新标签页中打开。在 Web 端，普通链接会在阅读器框架内打开，点「刷新」即可回到制品。在桌面端，所有外部链接都交给系统浏览器打开，制品保持不动。网页发起的下载照常进行。

「导出图片」可以把整页导出为一张长图，或只导出当前可视区域，格式可选 PNG、JPEG、WebP。如果网页里有不允许跨域访问（CORS）的图片或内嵌网页，截图会缺失这些内容，所以 EdgeEver 不会生成图片，并说明原因。遇到这种情况，可以改为导出当前可视区域，或修改网页。

### 卡片与缩略图

列表中的制品显示为卡片，上面是网页首屏的缩略图。打开列表的 Web 端或桌面端会在隐藏的沙箱框架里补渲染缺失的缩略图并上传，同一时间最多处理 2 个。无法截图的网页保留占位图。

### 离线

打开过的网页（以及生成过缩略图的网页）会缓存在当前设备上，之后离线也能打开。从没在本设备上打开过的网页需要联网加载，EdgeEver 会给出提示，而不是显示空白框架。导入、替换内容和恢复版本始终需要联网。

## 修改制品

- **标题、标签、位置**：和普通笔记一样，在阅读器或列表里修改。移动只能在制品库内进行。
- **替换内容…**：选择新的 HTML 文件（限制与导入相同）。之前的版本会自动保留，缩略图也会自动更新。
- **版本历史**：对比之前各版本的文字，并恢复其中一个版本，恢复后网页也回到该版本。
- 制品正文不能被人或工具直接编辑。试图修改正文的保存会被拒绝，返回 `artifact_update_required`（HTTP 409），制品保持原样。

## 在笔记中引用制品

- 在笔记里输入 `/card`（「制品卡片」），可以插入一张显示制品标题和缩略图的卡片，点击即可打开制品。
- `@` 提及和笔记链接选择器也会列出制品，并用网页图标标出。
- 卡片保存为一个只含一个笔记链接的普通段落。不支持卡片的客户端会把它显示为普通链接，保存时也会保留。制品被移入回收站或彻底删除后，卡片显示「制品不可用」。

## 回收站、恢复与彻底删除

制品的移入回收站、恢复和彻底删除与普通笔记相同。恢复的制品回到原来的文件夹；原文件夹已不存在时，回到制品库根目录。彻底删除会清除该制品保存的所有版本和缩略图。

## 分享

制品不能公开分享。制品没有笔记分享入口，制品库和制品文件夹不能分享，公开笔记本站点也永远不会包含制品。

## MCP 工具

通过 Remote MCP（「个人中心 → API / MCP」）或本地 MCP 服务连接的 Agent 可以用三个工具管理制品。内置助手不提供这些工具。

| 工具 | 权限范围 | 作用 |
| --- | --- | --- |
| `create_html_artifact` | `write:memos`、`write:resources`；只有需要创建制品库或文件夹时才需要 `write:notebooks` | 把一个 HTML 网页保存为制品 |
| `list_artifacts` | `read:memos`、`read:resources` | 列出某个文件夹及其子文件夹中的制品 |
| `get_artifact` | `read:memos`、`read:resources` | 返回单个制品的详情，按需返回 HTML |

`create_html_artifact` 的参数：

- `title`（1–160 个字符）和 `html`（完整网页字符串，UTF-8 下不超过 20MB）。
- `folderPath`（可选）：相对于制品库的路径，例如 `Reports/2026`。不存在的文件夹会自动创建；名称匹配不区分大小写；每一段最多 80 个字符；空段、`.` 和 `..` 会被拒绝。
- `tags`（可选）。
- `thumbnailBase64` 和 `thumbnailMimeType`（可选，需同时提供）：用作卡片缩略图的 PNG、JPEG 或 WebP 图片。不提供时，之后由 Web 端或桌面端补渲染。
- `source` 和 `externalId`（可选，需同时提供）：用于幂等导入的稳定标识。
  - 用同一组标识、同样的 HTML 再次调用，返回 `unchanged`。
  - HTML 不同时会替换内容、保留之前的版本，并返回 `replaced`。
  - 之前的制品已被删除时，会新建一个制品。
  - 不提供这组标识时，每次调用都会新建制品。

返回结果包含 `status`（`created`、`replaced` 或 `unchanged`）以及制品的 `id`、`title`、`folderPath`、`tags`、`thumbnailPending` 和 `missingLocalAssets`。

`list_artifacts` 接受 `folderPath`、`q`、`tag` 和 `limit`（最多 100）。`get_artifact` 接受 `id` 和 `includeHtml`。

通用笔记工具仍可用于修改制品的元数据：`update_memo` 可以修改标题、标签和所在文件夹，但不能修改正文；`move_memos`、`trash_memos`、`restore_memos` 和 `restore_memo_revision` 照常可用。不指定笔记本时，`list_memos` 不返回制品；`search_memos` 在没有查询词、标签和笔记本时也不返回制品。

Agent 可能遇到的错误：

| 错误码 | 含义 |
| --- | --- |
| `artifact_too_large`（413） | HTML 超过 20MB |
| `artifact_invalid_html`（400） | HTML 为空或不是 UTF-8 |
| `artifact_update_required`（409） | 试图通过笔记工具修改正文 |
| `artifact_location_invalid`（400） | 跨制品库边界移动 |
| `artifact_share_unsupported`（400） | 试图分享制品、制品库或制品文件夹 |
| `import_source_conflict`（409） | 这组 `source`/`externalId` 已属于一篇普通笔记 |

REST API 为脚本提供相同的操作：`POST /api/v1/artifacts`（multipart `file`，可选 `folderId`、`title`、JSON 数组形式的 `tags`、`thumbnail`）、`PUT /api/v1/artifacts/{id}/content`（multipart `file`，可选 `expectedRevision`、`thumbnail`）和 `POST /api/v1/artifact-library`。

## 安全沙箱

制品常常来自 Agent 或他人，所以 EdgeEver 把每个网页都当作不可信内容处理。

- 网页通过 `srcdoc` 加载到沙箱框架中，只开放 `allow-scripts allow-forms allow-modals allow-popups allow-popups-to-escape-sandbox allow-downloads`。网页运行在不透明源下：它的脚本读不到 EdgeEver 的 cookie、本地存储、登录状态、应用页面和你的笔记，不能让 EdgeEver 窗口跳转，也拿不到摄像头、麦克风和定位权限。框架只允许申请全屏。
- 服务端始终以下载方式返回保存的 HTML（`Content-Disposition: attachment`、`X-Content-Type-Options: nosniff`），浏览器永远不会在 EdgeEver 源下直接渲染它。
- 网页**可以**访问外网：它能从 CDN 加载脚本和图片，也能向任何接受请求的网站发送请求。不要导入你不愿在浏览器里打开的网页，也不要在其中输入密钥等敏感信息。
- 在桌面端，网页打开的链接交给系统浏览器，网页永远不能替换应用窗口。
- 缩略图和导出图片在同样的沙箱里运行，只通过一条会校验发送方的私有消息通道与应用通信。

## 移动端与旧版本

- **Android 和 iOS** 以只读方式显示制品：缩略图、简短的文字摘录，以及「请在 Web 或桌面端查看」的提示。你可以在制品文件夹之间移动制品（Android 上还能修改标签）。移动端不渲染网页，也不能导入制品。
- **旧版 EdgeEver 客户端**（HTML 制品发布之前的版本）连到新版服务端时，会把制品库显示为普通笔记本，把制品显示为带降级文字的笔记；旧版 Web 端还会把隐藏的信封显示为一长行注释。在旧版客户端里编辑这段文字时，服务端会拒绝保存，制品不会受损。之后旧版 Web 端会一直把这次未发送的修改显示为「待同步」，服务端也会一直拒绝它。请更新客户端来阅读制品。
- **服务端升级**：数据库新增一个可空列（Migration `0073_artifact_library`）。已有的笔记本和笔记不会改变，制品库只在第一次使用时创建。旧版服务端会忽略这一列，但它没有上述保护，所以在旧版服务端运行期间，旧版客户端可能覆盖制品正文。

## 备份

EdgeEver ZIP 备份（「个人中心 → 导入导出 → 导出 EdgeEver ZIP」）包含制品、制品的 HTML 和缩略图；从本版本起，还会记录哪个笔记本是制品库。

- 恢复到已有制品库的工作区时，备份中的制品库会作为一个文件夹放进现有制品库。
- 本版本之前的备份没有标记制品库。恢复到原工作区时，制品库保持不变；恢复到其他位置时，其中的制品会放到制品库根目录，旧的制品库及其文件夹会作为空的普通笔记本恢复，可以直接删除。

## 限制

| 项目 | 限制 |
| --- | --- |
| HTML 文件大小 | 每个网页 20MB（UTF-8） |
| 文件类型 | `.html`、`.htm`，UTF-8 编码，不能为空 |
| 标题 | 160 个字符 |
| `folderPath` 中的文件夹名 | 每段 80 个字符 |
| 缩略图 | PNG、JPEG 或 WebP；自动生成的缩略图宽 480px |
| 报告的缺失本地资源 | 前 50 个 |
| `list_artifacts` 每页 | 100 |

已知限制：

- 网页内的 `#章节` 锚点链接不会滚动到对应位置。
- 网页自己引用的相对路径资源需要在导入前内联或放到线上。
- 制品永远不会出现在随记（Jot）里（制品不会在收件箱里），也不会出现在公开笔记本站点中。
