# 随记是收件箱的卡片视图，复用笔记实体

引入 memos 风格的流式卡片时，我们决定不新建「短笔记」实体：随记中的每张卡片就是现有的笔记（Memo），随记只展示收件箱本身的笔记（不含子笔记本），快速输入固定存入收件箱，移出收件箱即视为整理完成。这样可以直接沿用笔记已有的资源、标签、搜索、同步、版本历史和回收站，不新增数据表；同时让随记有清晰的语义——待整理想法的入口，而不是全部笔记的另一种排列。回顾不受此限，覆盖整个工作区。

## Considered Options

- **新建独立短笔记实体（memos 做法）**：语义最干净，但资源、标签、搜索、同步、离线队列都要再做一套，还需要设计卡片转成笔记的流程。
- **随记展示整个工作区**：和 memos 一致，但大量长文会淹没短记录，随记失去「待整理入口」的定位。
